# KeyPoints

“Puntos Clave”: the unit summary, first box of every unit.

**Consumer provides:** 3–6 `items`, one sentence each.

It is the first box of every unit, right after `ChapterOpener`. It summarises the unit and does not introduce anything new. Write affirmative statements, not questions.

| Prop | Type | Required | Notes |
|---|---|---|---|
| `items` | `ReactNode[]` | yes | 3–6 key points, one sentence each. |
| `title` | `string` | no | Overrides “Puntos Clave”. |
