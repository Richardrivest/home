# ReferencesBox

“Referencias”: the unit's APA 7 reference list, French (hanging) indent. Children: <Reference> items.

**Consumer provides:** `Reference` children, sorted alphabetically.

It closes the unit and lists every work the unit cites, and only those, in APA 7 with a French (hanging) indent.

| Prop | Type | Required | Notes |
|---|---|---|---|
| `children` | `ReactNode` | yes | <Reference> items, alphabetical. |
| `title` | `string` | no | Overrides “Referencias”. |
