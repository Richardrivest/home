# Paragraph

Paragraph is the default reading text. It is set in `body` (11.5pt Cambria, 1.3 leading), in `ink`, justified with hyphenation, with `space-9pt` after.

**Consumer provides:** the text as children, including APA in-text citations. Links inside it take `link`.

**Do** cite as «(Autor, año)» or «Autor (año)». Use «…» for quoted terms and em dashes for asides. **Don't** bold whole sentences. For a definition, use a ConceptBox.
