# Glossary

Glossary built from entries, sorted alphabetically (Spanish collation); each entry is a link target for <Term>.

**Consumer provides:** `entries`, each `{ id, term, definition }`, in any order.

It sorts entries alphabetically with Spanish collation and gives each an anchor for `Term`. Keep definitions to one or two sentences ending with their citation.

| Prop | Type | Required | Notes |
|---|---|---|---|
| `entries` | `{ id; term; definition }[]` | yes | Entries in any order. |
