# BoxLegend

“Cómo usar este manual”: the legend of box types, grouped by family.

It renders the “Cómo usar este manual” legend: every box type with its icon and title, grouped into the three families (opening, in the text, closing).

Place it once, in the manual's introduction, after a sentence that explains the families.
