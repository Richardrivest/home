# CommonMistake

“Error Frecuente”: a common misconception and what the evidence shows instead.

**Consumer provides:** `misconception` (the belief, stated plainly) and `correction` (what the evidence shows, with its citation).

Place it next to the idea it corrects. Keep it respectful, so that it corrects the idea and not the reader.

| Prop | Type | Required | Notes |
|---|---|---|---|
| `misconception` | `ReactNode` | yes | The belief, stated plainly. |
| `correction` | `ReactNode` | yes | What the evidence shows, cited. |
| `children` | `ReactNode` | no | Optional teaching note. |
| `title` | `string` | no | Overrides “Error Frecuente”. |
