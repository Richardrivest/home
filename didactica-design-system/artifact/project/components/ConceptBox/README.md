# ConceptBox

ConceptBox is the «Concepto clave» callout. It condenses one definition the reader should retain. The box has a `concept-surface` fill, a `stroke-box` `concept-border` frame and square corners. Inside, a `concept-label` line in `navy` reads «CONCEPTO CLAVE — Término», followed by the definition in `concept-body`, justified.

**Consumer provides:** `term` and the definition as children (one paragraph, with its citation). `label` overrides the prefix.

**Use** it once or twice per unit, plus an «Idea-fuerza de la Unidad N» box near the end of each unit. **Don't** nest it, put lists or tables inside it, or add an accent stripe.
