# Reference

Reference is one entry of the reference list. It is set in `reference` (10.5pt Cambria) with an `indent-hang` hanging indent and `space-6pt` after. Titles of books and journals are italic, following APA 7.

**Consumer provides:** the reference as children, with the italic part wrapped in `<i>`.

**Do** sort references alphabetically. Write «y» between authors and add the DOI when one exists. Put an italic `note` paragraph before the list explaining the citation style. **Don't** number references.
